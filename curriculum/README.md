# 🐍🔥 Python & PyTorch Learning Curriculum

> **Goal:** Master the Python and PyTorch skills needed to read, understand, and build code from AI research papers.

## How to Use

This curriculum has **two ordered learning paths**. Complete them in order:

### 📘 Path 1: [Python for AI Engineers](python/python_path.md) (15 modules)
Everything you need to write Python fluently for AI/ML work — from basic syntax through NumPy, visualization, async programming, API building, and testing.

### 📕 Path 2: [PyTorch for AI Engineers](pytorch/pytorch_path.md) (21 modules)
From tensors to Transformers to diffusion models to deployment — every PyTorch concept you'll need as an AI engineer, including distributed training, model deployment, HuggingFace, and MLOps.

---

## Starting a Lesson

To begin learning, type a prompt like:

> *"Use the `learn-python-pytorch` skill to teach me Python Module 1: Python Foundations"*

Or simply:

> *"Teach me Python Module 1"*

The agent will deliver a detailed, interactive lesson and save comprehensive notes after you finish.

---

## After Completing Both Paths

Once you finish all 36 modules, return to [learning_tracker.md](../learning_tracker.md) and resume dissecting papers using the `dissect-paper` skill. You'll have the complete skillset to read paper code, build models, deploy them, and scale them!

---

## Platform

All code is designed to run on **Google Colab**. No local setup needed.
